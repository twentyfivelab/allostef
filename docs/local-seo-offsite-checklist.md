# Local SEO Off-site Checklist (AlloStef)

## 1) Google Business Profile

- Verify primary category and add secondary categories aligned to services.
- Ensure NAP consistency with website footer and contact sections.
- Add service areas: Oise and Val-d'Oise, then city-level priorities.
- Upload fresh photos monthly (before/after work, team, branded vehicle if available).
- Add weekly GBP post with one local service topic.

## 2) Reviews Program

- Ask for 2-4 reviews per month minimum.
- Use natural prompts with city + service context (no keyword stuffing).
- Reply to every review within 72h.
- Track review velocity and average rating monthly.

## 3) Citations and Directories

- Create/update listings on quality local directories.
- Keep exact same NAP and homepage URL.
- Add deep links for key pages where allowed.
- Record each listing in a tracking sheet (date, URL, status).

## 4) Local Backlinks

- Target local partners, suppliers, associations, and city/community pages.
- Prioritize relevance over volume.
- Acquire links to both homepage and local service pages.
- Track anchor text diversity and link destination balance.

## 5) 8-Week Execution Rhythm

- Week 1-2: Indexing checks + initial citations.
- Week 3-4: First backlink wave + content refinements on low-impression pages.
- Week 5-6: Review push + second backlink wave.
- Week 7-8: Consolidation, prune weak tactics, double down on pages gaining traction.

## 6) Decision Rules

- If indexed but low impressions after 3-4 weeks: add 2-3 internal links and expand FAQ.
- If impressions grow but CTR is low: improve title and meta description.
- If CTR is strong but position stagnates: add authority links and richer supporting content.
